# ANNIN 登録・入金チェックアプリ

スプレッドシート「ANNIN_タレント管理シート（kintone移行版）」に組み込む Apps Script です。
アプリに入力すると、スプレッドシートに自動で書き込まれます。

## できること

### 新規登録

| 入力項目 | 書き込み先 |
|---|---|
| ① ANNIN No.（空欄なら自動で振る） | 3シートすべてのA列 |
| ② 姓・名 | 10_タレント台帳（姓・名）、20_受領管理・30_個人情報（姓名） |
| ③ 読み方（セイ・メイ） | 10_タレント台帳（姓（カナ）・名（カナ））。ひらがなで入力してもカタカナにそろえる |
| ④ 所属（東京／大阪） | 10_タレント台帳・20_受領管理（所属事務所） |
| ⑤ 開始月 | 10_タレント台帳・20_受領管理（開始年月） |
| ⑥ 住所（郵便番号・住所・電話番号） | 30_個人情報（銀行口座） |
| ⑦ 銀行情報（銀行名・支店名・区分・口座番号・口座名義） | 30_個人情報（銀行口座）。銀行名と口座番号があれば台帳の「銀行情報登録」を「済」にする |

- **ANNIN No. がかぶらない仕組み**：3シートで使われている番号の最大＋1を振ります。手入力した番号が使用済みなら登録しません。同時に2人が登録しても番号が重ならないよう、登録中はロックをかけます。
- **開始月の入金**：登録と同時に、20_受領管理の開始月にステータスを入れます。「入金あり（振込）」（初期値。支払方法が空欄なら振込にする）・「サブスク」・「当月開始（入会金のみ）」・「入れない」から選べます。開始月の列が受領管理にないときは入れずに知らせます。
- 同じ姓名の人がすでにいるときは確認が出ます（別人ならそのまま登録できる）。
- 数式が入っている列（入金月数・最終入金月・ステータス・対象月チェックなど）は、1つ上の行の数式をそのまま引き継ぎます。書式・チェックボックス・プルダウンも上の行からコピーします。
- 口座番号・郵便番号は「書式なしテキスト」で書き込むので、先頭の0が消えません。

### 入金チェック（ステータス入力）

- **探して入力**：対象月を選び、ANNIN No. か名前（漢字・カナ・ひらがな、部分一致）で検索 → 「振込」「サブスク」「未入金」「休止」「退所」のボタンを押すとすぐ記録されます。「振込」はその月を「入金あり」にして、支払方法を「振込」にします。ほかのステータス（当月開始・翌月支払い・クーオフ）や、支払方法（振込・スクエア・JMS）・着金日はプルダウンで選んで「保存」。「（空欄）」を選ぶと空欄に戻せます。
- **まとめて入力**：振込明細などから ANNIN No. をまとめて貼り付け、「振込にする」「サブスクにする」を押すか、ステータス・支払方法・着金日を選んで一括で入れます（初期値は入金あり＋振込）。変更がなかった番号・見つからない番号は結果に表示されます。
- 20_受領管理がまだチェックボックス形式のときは、入金あり・サブスクは「チェックあり」、それ以外は「チェックなし」として記録します（支払方法・着金日は記録しません）。
- 20_受領管理にその月の列がないとエラーになります。メニュー「受領管理に次の12ヶ月の列を追加」で列を足してください。

### 受領管理のステータス形式（チェックボックス → プルダウン）

メニュー「ANNIN管理 → 受領管理をステータス形式に変換（最初に1回だけ）」で、20_受領管理 を次の形にします。

| 変わるところ | 内容 |
|---|---|
| 月の列 | チェックボックス → プルダウン：当月開始／入金あり／サブスク／翌月支払い／未入金／休止／退所／クーオフ。ステータスごとに色分け |
| 今までのチェック | チェックあり → 入金あり。チェックなし → 在籍中の人の開始月〜先月は未入金、それ以外は空欄 |
| 列の追加 | 開始年月の右に「支払方法」「着金日」 |
| 集計行 | いちばん上に、月ごとの入金済み計とステータスごとの人数 |
| 数式 | 入金月数・最終入金月・対象月チェック、50_月次推移を、ステータスで数えるように書き直す |
| 10_タレント台帳 | 入金月数・最終入金月・ステータス・銀行情報登録を、ANNIN No. で探す数式に書き直す |
| 足りない行 | 台帳にいて受領管理・個人情報にいない人の行を追加 |
| タイムゾーン | スプレッドシートのタイムゾーンを東京にする |

- **入金済み**として数えるのは「入金あり・サブスク」です。**当月開始**（入会金は払ったが月謝はまだの月）と**休止・退所・クーオフ**の月は入金対象から外れます（入金済みにも未入金にも数えない）。コード先頭の `STATUS` で変えられます。
- 変換前の 20_受領管理 は「20_受領管理_変換前_日時」という非表示シートに残ります。
- 変換すると、シートの条件付き書式は新しい色分けに置き換わります。
- **10_タレント台帳の行ずれを直します**：これまで台帳の入金月数・最終入金月・ステータスは、受領管理の「同じ行番号」を見ていました。台帳にだけ手で行を足すと、それより下の人は別人の値になっていたため、ANNIN No. で探す数式にします。
- 変換後に月の列を追加したとき・シートを手で直したときは、メニュー「受領管理の色分け・集計・数式を整える」を押すと、プルダウン・色・集計行・数式・台帳・ダッシュボードを整え直します（何度押しても安全）。
- メニュー「入金ありの人の支払方法を「振込」にする（空欄の人だけ）」で、どこかの月が入金ありの人のうち支払方法が空欄の人を、まとめて振込にできます（変換直後に1回使う想定。入っている支払方法は上書きしません）。
- 旧「00_ダッシュボード」「未入金者一覧」はそのまま残りますが、台帳と受領管理の行番号がそろっている前提の数式なので、数字は「01_入金ダッシュボード」を見てください。

### 入金ダッシュボード

メニュー「ANNIN管理 → 入金ダッシュボードを作成・更新」を押すと、2枚目のタブに「01_入金ダッシュボード」ができます。
中身はすべて数式なので、アプリやシートでステータス（チェック）を入れるとすぐに数字が変わります（作成は最初の1回だけでOK）。

| 場所 | 内容 |
|---|---|
| B3（黄色） | 対象月。**空欄なら毎月自動で今月**になる。プルダウンで過去の月も選べる |
| B5（黄色） | 月謝（初期値30,000円）。入金額の計算に使う |
| サマリー | 入金対象（在籍・開始済み）／入金済み／未入金／入金率／入金額／前月の入金済み・前月比／今月から開始（新規）／在籍数 |
| 事務所別 | 東京・大阪・合計ごとの入金対象・入金済み・未入金・入金率 |
| ステータス別 | 対象月のステータスごとの人数（ステータス形式のときだけ） |
| 支払方法別 | 対象月の入金済み（入金あり・サブスク）を、20_受領管理の「支払方法」（振込・スクエア・JMS・未設定）で分けた人数（ステータス形式のときだけ） |
| 月別の入金済み数 | 対象月までの直近12ヶ月の入金済み数・前月差と、棒グラフ |
| 未入金者一覧（右側） | 入金対象のうち、対象月が入金済みでない人（No.順・ステータスつき） |

- 「入金対象」は、10_タレント台帳で解約にチェックがなく、開始年月が対象月以前で、対象月が当月開始・休止・退所・クーオフでない人です。
- 「入金済み」は、対象月が入金あり・サブスク（チェックボックス形式ならチェックあり）の全員の数です（50_月次推移の受領者数と同じ数え方）。
- 支払方法は人ごとの列なので、支払方法別は「今その人に登録されている支払方法」で分けます。
- 計算用の「_入金集計」シートは非表示にしています。消したり編集したりしないでください。
- シートの列を追加・削除して数字がおかしくなったら、もう一度メニューから「作成・更新」を押してください。B3・B5の値は残ります。

## セットアップ（管理者が1回だけ）

1. スプレッドシートの「拡張機能 → Apps Script」を開く
2. `ANNIN_登録入金.gs` の中身をすべて貼り付けて保存する
   - すでに別のスクリプトに `onOpen` がある場合は、その `onOpen` の中に、このファイルの `onOpen` の中身（メニュー追加）を移してください
3. 「プロジェクトの設定」でタイムゾーンを「(GMT+09:00) 東京」にする
4. 関数 `onOpen` を一度実行して権限を承認する
5. スプレッドシートを開き直すと、メニューに「ANNIN管理 → 登録・入金アプリを開く」が出る

### スマホから使う場合（ウェブアプリ）

1. Apps Script の「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
2. 実行ユーザー：**自分**、アクセスできるユーザー：**自分のみ**（または組織内のユーザー）
   - 住所・口座情報を書き込むアプリなので、**「全員」にはしないでください**
3. 表示されたURLをスマホのホーム画面に追加すると、アプリのように使えます
4. コードを書き換えたら「デプロイを管理 → 編集 → バージョン：新バージョン」で更新します

## シート名・列名を変えたとき

コード先頭の `SHEET`（シート名）と `COLS`（列の見出しの候補）を書き換えてください。
列は見出しの名前で探すので、列の順番を入れ替えても動きます。

## テスト

```bash
node --test annin-talent/tests/*.test.js
```

スプレッドシートのモックで、番号の採番・3シートへの追加・数式の引き継ぎ・検索・入金チェック・ダッシュボードの数式（括弧の対応・参照先の列）・ステータス形式への変換と列の追加を確認しています。
