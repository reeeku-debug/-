# ミクチャ ティア判定（月次CSV取込・ティア自動判定・売上ダッシュボード・社内アプリ）

REALITY版（`reality-tier/`）と同じ形のミクチャ版です。`MIXCH_ティア.gs` を新しい Google スプレッドシートに貼るだけで、シート・ダッシュボード・アプリが揃います。

## セットアップ（1回だけ）

1. Google ドライブで新しいスプレッドシートを作る（例：ミクチャ_ティア判定）
2. 「拡張機能 → Apps Script」を開き、最初のコードを消して `MIXCH_ティア.gs` を全文貼り付けて保存
3. プロジェクトの設定でタイムゾーンを「(GMT+09:00) 東京」にする
4. 関数 `setupMixch` を実行して権限を許可する（設定・タレントマスタ・月次RAW・取込ログ・ティア判定・タレント分け・売上ダッシュボードを作る）
5. スプレッドシートを開き直し、メニュー「ミクチャ取込 → ミクチャcsvのスプシから取り込む（大元・ぷちの全月）」を実行
   - 「ミクチャcsv」スプレッドシートの「大元10月」「ぷち9月」などのシートをまとめて取り込みます
6. アプリ：「デプロイ → 新しいデプロイ → ウェブアプリ」、次のユーザーとして実行＝**自分**、アクセスできるユーザー＝**株式会社LIV 内の全員**
   - 表示された「ウェブアプリ URL（…/exec）」を社内に共有

## 毎月の使い方

- ミクチャ管理画面の月次CSV（大元・ぷち）を、アプリの「CSVを取り込む」かメニュー「CSVをアップロードして取込…」で入れる
- 対象月はファイル名から推測します（違うときは画面で直す）。同じ月・同じ区分のデータは新しいCSVでまるごと置き換わります
- 区分は「所属プロモーター名」で決まります：`アソビシステム株式会社(ASOBINEXT)`＝大元、`アソビシステム株式会社-ASOBINEXT-`＝ぷち（設定シートの対応表で変更可）

## シート（REALITYのティア表と同じ並び）

| シート | 内容 |
|---|---|
| マニュアル | ティアの定義・細則・シートの見方・毎月の流れ（設定シートの値で自動作成） |
| 売上ダッシュボード | B3で選んだ月の売上パネル・大元／ぷち別・ティア別（目標つき）・月別推移・上位10人・グラフ |
| 月別ティア | B3で選んだ月のティア別人数（前月・増減・昇格／降格）と、ティアごとのメンバー（前月のティアつき） |
| ティア判定 | B3で選んだ月の全員の判定・理由・次の目標 |
| サマリー | 評価月のティア別人数（大元／ぷち・構成比・売上）と目標管理（月初の人数・新規目標・担当・移動の内容は手入力で、更新しても残る） |
| タレント分け | B3で選んだ月のティアごとのメンバー |
| ティア推移 | 全月のティア別人数と、タレントごとの月別ティア |
| タレントマスタ | 担当者・パーソナル枠・イベント3回・特例ティア入り月・本部長承認・デビュー月・メモ（手入力。アプリからも保存可） |
| 設定 | ティア入り時間・イベント回数・ティア1/2の売上・初月ルール開始月・評価月・目標人数・プロモーター名→区分 |
| 月次RAW／取込ログ | 取り込んだCSVの月ごとの数値と取込の記録 |

REALITY版にある「週次KPI」は、ミクチャのCSVが月単位（日次の累計がない）なので作っていません。

## ティアのルール（NEXT_ミクチャ_Tier表と同じ）

- 売上＝プロモーター獲得分（税抜）＋ライバー獲得分（税抜）、会社売上＝プロモーター獲得分
- ティア入り：初月ルール開始月（既定 2026/10）以降のデビューは、デビュー月に60h配信＋イベント3回。それより前からいる人は、60h配信した最初の月
- ティア入り済み（またはタレントマスタで特例ティア入り月あり）で直近3ヶ月に配信がある人：月売上50万以上＝ティア1（本部長承認○）／ティア1候補、25万以上＝ティア2、それ以外＝ティア3
- それ以外はパーソナル枠（○）かティア外。イベント3回が「×」の人はティア入りしません
- デビュー月はタレントマスタの値、空欄なら初めて配信した月

## アプリの画面を直すとき

`webapp/App.html` を編集して `node mixch-tier/build.js` を実行すると、`MIXCH_ティア.gs` の `MX_APP_HTML_` に埋め込まれます。
